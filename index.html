Quick Google Sheets Setup Guide

  1. Open a new Google Sheet.
  2. Go to Extensions > Apps Script.
  3. Copy & paste the code from google-apps-script/Code.gs.
  4. Click Deploy > New deployment.
  5. Select Web app, execute as Me, and access as Anyone.
  6. Copy the Web App URL and paste it above!
